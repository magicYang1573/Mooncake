# KV Event Dynamo Integration Notes

This directory contains intermediate design and analysis notes for the Mooncake KV event integration with Dynamo KV-aware routing.

These files are development materials for discussion and implementation planning. They are intentionally not added to the public documentation toctree yet.

## Files

- `mooncake开发方案.md`: proposed Mooncake-side development plan and interface design.
- `mooncake_kv_event_rules.md`: current Mooncake KV event behavior and field analysis.
- `dynamo_kv_event_rules.md`: Dynamo KV event requirements and field analysis.
- `kv_event_alignment_report.md`: comparison between Mooncake events and Dynamo requirements.
- `mooncake_sglang_interaction_layers.md`: Mooncake and SGLang interaction layers relevant to KV event metadata propagation.
